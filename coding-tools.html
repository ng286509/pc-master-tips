Coding & Developer Tools

Understand common beginner tools for writing code, managing projects and learning programming safely.

1. Code editor

A code editor helps you write and organise source files. Visual Studio Code is one popular option. Learn to create folders, open files, use search and save changes.

2. Terminal basics

  • pwd — show current directory (Linux/macOS).
  • ls — list directory contents (Linux/macOS).
  • cd folder — change directory.
  • mkdir project — create a folder.
  • python --version — check Python availability.
Commands vary between Windows PowerShell, Command Prompt and Linux shells. Check the documentation for your environment.

3. Version control

Git records project changes so you can review work and return to earlier versions. GitHub can host repositories and static websites.

  • Use meaningful commit messages.
  • Do not upload passwords, private keys or personal documents.
  • Review files before making a repository public.

4. Learn by building

Start with a personal profile page, a simple calculator, a to-do list or a file-organising script. Build small features, test them and document what you learn.
