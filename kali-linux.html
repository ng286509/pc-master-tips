Kali Linux: Beginner Commands

Start with everyday terminal commands. Read the explanation and practise inside your own Kali Linux virtual machine.

01. Know where you are

CommandWhat it does
pwdShows your current directory.
lsLists files and folders.
ls -laLists all entries, including hidden files, with details.
whoamiShows the current username.

02. Move around and manage folders

CommandWhat it does
cd DocumentsMoves into Documents (if it exists here).
cd ..Moves up one directory.
cd ~Returns to your home directory.
mkdir practiceCreates a folder named practice.
touch notes.txtCreates an empty file named notes.txt.

03. Read and search text

CommandWhat it does
cat notes.txtPrints a text file to the terminal.
less notes.txtOpens a file for page-by-page reading; press q to quit.
grep "word" notes.txtFinds lines containing the given word.

04. Check system and network information

CommandWhat it does
uname -aDisplays kernel and system information.
df -hShows disk space usage.
free -hShows memory usage.
ip addrDisplays network interface addresses on your machine.
ip routeDisplays your system's routing table.

05. Update package information

sudo apt update refreshes the package lists. It does not upgrade installed applications by itself.

Only run commands you understand. Use security-testing tools only against systems you own or have explicit permission to test. Never scan or access someone else's device without permission.

06. A–Z Command Quick Reference

Here is a beginner-friendly alphabetized selection of useful commands. Some letters have more than one example; this is a learning list, not every command available on Linux.

LetterCommandUse
AaptManage software packages.
AawkProcess and format text columns.
BbasenamePrint the final part of a path.
CclearClear the terminal display.
CchmodChange file permissions.
DdateShow the current date and time.
Ddu -shShow the size of a folder.
EechoPrint text or variable values.
FfileIdentify a file's type.
FfindSearch for files and folders.
GgrepSearch text for a pattern.
HheadShow the first lines of a file.
HhostnameShow the computer's host name.
IidShow user and group IDs.
IipView network interface and route information.
JjournalctlRead system service logs.
KkillSend a signal to a process you own or administer.
LlessRead long text one screen at a time.
LlnCreate links to files or folders.
MmanOpen a command's manual page.
MmkdirCreate a directory.

OodDisplay file data in a chosen format.

Safety tip: commands such as rm, chmod, kill and commands using sudo can change your system. Read the manual with man command-name and check paths before running them.
