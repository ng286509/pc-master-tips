Computer Basics

Learn the essential parts of a computer, common terms, files, folders and safe everyday computer habits.

1. What is a computer?

A computer is an electronic device that accepts input, processes data, stores information and produces output.

  • Input: keyboard, mouse, microphone, scanner.
  • Processing: CPU performs instructions.
  • Storage: SSD, HDD, USB drive.
  • Output: monitor, printer, speakers.

2. Hardware and software

Hardware is the physical equipment. Software is the operating system and applications that tell the computer what to do.

  • Hardware examples: motherboard, RAM, CPU, SSD, monitor.
  • System software: Windows, Linux, device drivers.
  • Applications: browser, office suite, image editor.

3. Files, folders and extensions

A folder organises files. The file extension usually indicates its format.

  • .txt text file
  • .pdf document
  • .jpg / .png image
  • .mp4 video
  • .zip compressed archive
Show file extensions in File Explorer so you can spot misleading filenames. Do not open unexpected attachments.

4. Basic computer care

  • Keep software and security updates current.
  • Back up important files to a separate drive or trusted cloud service.
  • Keep ventilation clear and shut down properly.
  • Download apps from trusted sources.
  • Use a standard account for everyday tasks when possible.
