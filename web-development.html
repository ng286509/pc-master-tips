/// BUILD THE WEB

Web Development Basics

Start learning HTML, CSS and JavaScript and understand how a simple website is built.

1. HTML — page structure

HTML describes the content and structure of a page.

<!doctype html>
<html lang="en">
<head><title>My Page</title></head>
<body>
  <h1>Hello, world!</h1>
  <p>My first webpage.</p>
</body>
</html>

2. CSS — visual design

CSS controls colours, spacing, typography and responsive layout.

body {
  font-family: Arial, sans-serif;
  background: #f4faf6;
  color: #173d27;
}
h1 { color: #087b3b; }

3. JavaScript — interaction

JavaScript responds to user actions and updates the page.

const button = document.querySelector("button");
button.addEventListener("click", () => {
  alert("Hello from JavaScript!");
});

4. A good learning workflow

  • Create a project folder and keep HTML, CSS and JS organised.
  • Use descriptive filenames and readable indentation.
  • Test at desktop and mobile widths.
  • Check links, keyboard navigation and browser console errors.
  • Never place passwords, API keys or private tokens in public frontend code.
