Windows 10 & 11 Tips

Useful keyboard shortcuts, built-in tools and basic Command Prompt commands to help you use Windows confidently.

01. Useful Keyboard Shortcuts

ShortcutWhat it does
Win + EOpen File Explorer
Win + ROpen the Run dialog
Win + IOpen Windows Settings
Ctrl + Shift + EscOpen Task Manager
Win + Shift + SCapture a selected screenshot
Alt + TabSwitch between open apps
Win + DShow or hide the desktop
Win + LLock your computer

02. Useful Run Commands

Press Win + R, type a command and press Enter.

CommandPurpose
notepadOpen Notepad
calcOpen Calculator
mspaintOpen Paint
winverView Windows version information
services.mscOpen Services management
taskmgrOpen Task Manager
appwiz.cplOpen Programs and Features

03. Beginner CMD Commands

Open Command Prompt. These commands display information or navigate folders.

CommandPurpose
whoamiShow the current account
hostnameShow the computer name
ipconfigShow network configuration
systeminfoShow Windows system details
dirList files and folders
cd DesktopChange to the Desktop folder (if it exists in the current location)
clsClear the Command Prompt screen
Be careful with commands that delete, format or change system settings. Learn what a command does before running it.

04. Basic PC Maintenance

  • Install Windows updates from Settings.
  • Keep important files backed up.
  • Uninstall apps you no longer use.
  • Keep enough free space on the system drive.
  • Use Windows Security and avoid unknown downloads.
