Technology Tutorials

Welcome to the PC Master Tips learning area. Start with the basics, practise in your own lab, and build your skills step by step.

01. Kali Linux & Terminal Basics

Learn the Linux terminal and understand what each command does before running it.

  • pwd — show your current folder.
  • ls — list files and folders.
  • cd Documents — move into the Documents folder.
  • mkdir practice — create a practice folder.
  • ip addr — view network interface information on your own device.
Practise commands in your own Kali Linux virtual machine. Use security tools only on systems you own or have permission to test.

02. Windows Tips

Useful shortcuts to work faster on your Windows computer.

  • Win + E — open File Explorer.
  • Win + R — open the Run dialog.
  • Ctrl + Shift + Esc — open Task Manager.
  • Win + Shift + S — capture a selected screenshot.

03. Cyber Security Awareness

Learn to recognise suspicious links, fake login pages, unsafe attachments and social-engineering attempts.

  • Check the website address before entering information.
  • Use unique passwords and enable multi-factor authentication.
  • Never share OTPs, passwords or recovery codes.
  • Practise phishing awareness with dummy data in a private training lab only.
